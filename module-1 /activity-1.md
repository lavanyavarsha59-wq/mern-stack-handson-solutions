# Activity 1: How the Internet Works
 Students simulate the interaction between a browser, server, and database to understand how requests are processed and responses are returned. 
 # Activity 1: How the Internet Works

## 1. Aim

To understand how a browser, web server, and database communicate to process a request and return information to the user.

## 2. Requirements

Four students to act as the user, browser, web server, and database.

## 3. Flowchart

START

1\. USER

Opens a website and requests information

2\. BROWSER

Sends an HTTP request to the server

3\. WEB SERVER

Receives and processes the request

4\. DATABASE

Retrieves the requested information and returns it to the server

5\. WEB SERVER

Sends the HTTP response to the browser

6\. BROWSER

Displays the requested information to the user

END

## 4. Procedure

1. The user opens a college website in a browser.
2. The browser sends a request to the web server.
3. The web server processes the request.
4. The server asks the database for the required information.
5. The database returns the information to the server.
6. The server sends a response to the browser.
7. The browser displays the information on the screen.

## 5. Example

Suppose a student wants to check examination results.

- User: Wants to view the results.
- Browser: Sends the request.
- Web server: Requests the student's marks.
- Database: Returns the marks.
- Web server: Sends the results to the browser.
- Browser: Displays the results to the student.

## 6. Expected Outcome

Students understand the roles of the browser, web server, and database and how they work together to retrieve and display information.

## 7. Conclusion

When a user requests information from a website, the browser sends a request to the web server. The server retrieves the required data from the database when necessary and sends a response back to the browser, which displays the information to the user.

Remember: Request → Server processing → Database retrieval → Response → Display.

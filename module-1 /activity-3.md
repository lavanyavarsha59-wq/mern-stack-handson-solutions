 # Activity 3: Real-World Scenario Mapping

## 1. Aim

To identify the frontend, backend, and database components of everyday applications and understand how they work together.

## 2. Requirements

- Paper and pen
- Examples of everyday applications such as WhatsApp, Instagram, YouTube, and Amazon
- Computer for drawing flowcharts (optional)

## 3. Procedure

1. Divide students into small groups.
2. Ask each group to select an application they use daily.
3. Identify the frontend, backend, and database components of the selected application.
4. Explain the function of each component.
5. Draw a flowchart showing how the components communicate.
6. Ask each group to present its findings to the class.

## 4. Flowchart: How an Application Works

START

USER

Opens an application

FRONTEND

Displays the screen and accepts user input

BACKEND

Processes the user's request

DATABASE

Stores or retrieves the required information

Returns data to the backend

BACKEND

Sends the response to the frontend

FRONTEND

Displays the result to the user

END

## 5. Real-World Examples

| Application    | Frontend                        | Backend                                   | Database                                   |
| -------------- | ------------------------------- | ----------------------------------------- | ------------------------------------------ |
| WhatsApp       | Chat screen and message input   | Handles message delivery                  | Stores account and relevant message data   |
| Instagram      | Posts, stories, and profiles    | Processes likes, comments, and follows    | Stores profile, post, and interaction data |
| YouTube        | Video player and search page    | Handles searches and video requests       | Stores video details and user data         |
| Amazon         | Product pages and shopping cart | Processes orders and inventory requests   | Stores product, customer, and order data   |
| College portal | Login page and results screen   | Authenticates users and retrieves results | Stores student records and marks           |

These are simplified examples. Actual applications may use multiple services, databases, and storage systems.

## 6. Example Scenario: Instagram Like Button

1. The user opens Instagram and views a post.
2. The frontend displays the post and Like button.
3. The user clicks the Like button.
4. The backend processes the like request.
5. The database records the interaction, as appropriate.
6. The backend sends a response to the frontend.
7. The frontend updates the Like button to show the result.

## 7. Expected Outcome

Students will be able to identify frontend, backend, and database components in everyday applications, explain their functions, and represent their interaction using a flowchart.

## 8. Conclusion

Everyday applications use three important components: the frontend provides the user interface, the backend processes requests, and the database stores or retrieves information. These components work together to provide users with the features they need.
